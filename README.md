# Schnick Schnack Schnuck – Sammelkarten

Kartengenerator und Druckwerkstatt für ein eigenes Sammelkartenspiel zu Schere, Stein, Papier.

- 41 Karten in sechs Seltenheiten: Gewöhnlich, Ungewöhnlich, Selten, Episch, Legendär, Mythisch
- Jede Karte schlägt immer feste Gegner, es gibt kein Unentschieden
- Gleiche Karten: höhere Zahl (1–1000) gewinnt, bei gleicher Zahl gibt es einen Stich
- Auf den Karten stehen keine Gesamtzahlen oder Siegzahlen, damit später neue Karten und Seltenheiten dazukommen können, ohne alte Karten neu zu drucken

## Funktionen

- Katalog mit allen Karten und ihren festen Siegen und Niederlagen
- Zufallsziehung von X Karten mit einstellbarer Seltenheits-Verteilung
- Druckliste mit A4-Bogen, 3 × 3 Karten zu 63 × 88 mm, Schnittmarken und optionalen Rückseiten
- Kampfrechner für zwei Karten

## Drucken

Im Druckdialog Skalierung 100 %, keine Ränder und Hintergrundgrafiken einschalten.

## Veröffentlichen (Cloudflare Pages)

Repository verbinden, Build-Befehl leer lassen, Ausgabeverzeichnis `public`. Die ganze App ist die Datei `public/index.html`.
